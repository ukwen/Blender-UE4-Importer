# 0.10.72-dev — saved masked character materials

The objective is faithful native project/asset reconstruction in Blender, not Unreal gameplay emulation. With partial editor materials explicitly enabled, supported default-lit surface masks are connected to a Principled/transparent mix, with a binary greater-than-or-equal clip comparison. The root material clip threshold is decoded when serialized; otherwise an editable 0.3333 preview value is explicitly marked as not serialized. Unsupported base overrides, non-default-lit shading models and connected dynamic shading, displacement, refraction or pixel depth offsets are excluded. Strict mode still reports partial material metadata only.

The original M_Mannequin graph uses Lerp(1, Sign(Length(camera-relative world position) - Head Cutout), IsFirstPerson). Length of that specific source camera-relative position is previewed with Blender Camera Data View Distance converted from metres to centimetres. IsFirstPerson is an editable manual 0/1 control defaulting to 0 (third-person); no automatic Unreal runtime or projection inference. Other explicit WorldPosition modes remain unsupported. Generic vector Length is supported. Renderer ray behavior, material shadows, clip edges and Unreal first-person projection equivalence are not certified. Additive and vector-opacity coercion are unchanged.

Original ShooterSam source: three 96×96 Cycles perspective camera renders, using the serialized 16.40704345703125 cm head cutout and an edited 20 cm radius. 26,016 interior pixel checks (boundary within 0.5 cm excluded for first-person) all exactly matched independent source-formula alpha; 0, 2,440 and 5,276 clipped pixels respectively. Saved/reopened .blend and strict refusal verified. Actual character Blueprint imports BP_ThirdPersonCharacter and BP_CombatEnemy include 43,761 and 46,098 vertices, 89 bones each, 4 available sockets each and two masked material slots each. Packed source texture node counts 6 and 7 (Manny's original logo is retained). Missing body rejection preserved. No claim of Unreal renderer parity. Material revision 072 invalidates previous material-dependent import fingerprints.
