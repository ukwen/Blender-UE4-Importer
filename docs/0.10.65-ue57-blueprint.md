# 0.10.65-dev — UE5.7 saved Blueprint composition

File → Import → **UE5.7 Blueprint Component Preview (.uasset)** inspects the UE5 object version 1018 tagged editor class. It builds a separate editable anchor collection and an embedded JSON report. This is not a geometry importer or runtime emulator. No source assets are changed. Duplicate source collections are refused; explicitly remove the previous collection to import again.

- Read the generated class, native superclass identity, explicit CDO object references and active SimpleConstructionScript nodes. Root aliases are deduplicated by export index. SCS component class, template ownership, parent/child graph, native parent names and active/inactive node membership are checked. Invalid indices, cycles and ambiguous components are rejected. Native constructor attachments are not inferred.
- Preserve explicit transforms, mesh identities, camera settings, owner visibility, primitive type, selected scalar fields and referenced classes. Absent transforms use neutral local preview values, not asserted native constructor defaults. Unsupported property names remain in the report. Socket attachments without an evaluated skeleton, non-scene components and unresolved parents are metadata-only; no false world transform is created.
- All five original UAssetAPI TestEditorUE5_7 Blueprint packages inspected and imported through Blender 4.2.4's actual operator: two camera managers, character, game mode and player controller. Ten active components total, eight anchors; first-person camera attached to `head` and movement component metadata-only. The two Manny mesh bindings are preserved separately with owner-visibility flags. Camera FOV 70 degrees, first-person scale 0.6; camera managers' pitch min/max -70/80 degrees. Source transform differences <=0.000022 mm on the eight anchors after independent reopen; no UE-evaluated world pose claim. Malformed SCS array refused. No duplicate objects on repeat import. 68 Python tests passed.
- The supplied UE5.7 fixture lacks the referenced mannequin geometry, animation, materials and level packages. This does not validate UE5.7 mesh payloads, runtime Blueprint, rendering, first-person camera pose or visibility behavior. UE5.6 lighting is still an approximate preview, and missing project/engine assets and 0.10.63 material/animation runtime limitations remain.
