# 0.10.51-dev: modern UE5 cooked assets

Source fixtures: UAssetAPI.Tests/TestAssets from the original UAssetAPI reference archive. Explicit profiles, not automatic claims of compatibility with all assets of the named version.

* UE5.4 BlankGame SM_BlueCube, UE5.5 BlankGame SM_Cube, UE5.6 BpThirdPerson SM_Cube: 24 vertices and 12 triangles each. UV channels 2/1/2; material slots 1/2/1. UE5.5 slot face counts 10 and 2. Native package identity and hard references preserved. Only ordinary inline render buffers reconstructed; opaque tail and external Nanite/collision data are not reconstructed.
* MI_BlueCube and MI_Quinn_01: seven serialized scalar/vector/texture overrides total, parent package and streaming metadata preserved. Editable unconnected Blender parameter nodes, not a recreation of the compiled parent shader. Missing textures and parent graphs remain unresolved.
* UE5.5 T_Test: BC1 2048x2048, 12 mips, 5 external and 7 inline. All 12 decoded pixel buffers match Pillow DDS decoding exactly. Original bulk extent and mip dimensions validated; missing/truncated bulk rejected.

Acceptance: 31 Python tests, Blender 4.2.4 modern gallery, direct import operators, native package inspection, source mesh/UV/material-index checks, packed texture and save/reopen, duplicate-free batch reuse. UE5.0 gallery, UE4.18/4.27 static geometry and registration regressions passed. Full Western Frontier and Goblin map regressions not repeated.

Tests: `tests/test_ue5_modern_static.py` and `tests/blender_ue5_modern_static.py` (see fixture environment variables in the scripts). Actual modern editor geometry, modern skeletal render LODs, IoStore, Nanite clusters, other texture codecs/profiles and compiled parent shader translation are not supported by this milestone.
