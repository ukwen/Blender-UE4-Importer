# 0.10.36-dev: native editor skeletal vehicle reconstruction

Bounded monolithic versioned UE4.27 editor skeletal LOD0 decoder for the supplied custom-version profile. Sequentially decodes material slots, embedded reference bones, full-precision source vertices, four stored UV channels, BGRA colors, 16-bit palette indices restricted to 0-255, 12-slot 8-bit weights, section index buffers and local palettes; validates overlap references and source vertex counts. Remaining LOD metadata is explicitly unparsed and recorded as byte count. Does not decode subsequent LODs, raw source import vertex map, morphs, cloth, physics or animation. Material slots use placeholders. No shader-development changes. Identical duplicate triangles with same order and material can be collapsed with source-face index and removed-index metadata; conflicting duplicates rejected. Native skeletal operator, project geometry gallery and skeletal map routing use shared editor/cooked dispatch.

Genuine 13 user-provided vehicle assets: 357302 vertices, 134606 original triangles, 134605 Blender triangles after removing the exact duplicate War Balloon source face 21487, 70 bones. All original vertex weights matched Blender vertex groups and were normalized. 13 independent pose tests against explicit weighted Blender pose/rest matrices: maximum error 7.229403301679458e-07 m; all moved and returned to neutral. Saved/reopened gallery and actual Overview map: 13 independent original vehicle armatures, 3 original static meshes, 559 missing static references and two missing standalone skeletal cape meshes; Blueprint transforms and socket attachments unresolved. No independent Unreal render or original animated pose comparison. 14 Python tests and five Blender executions (editor vehicles including original map, both cooked skeletal versions, project gallery, smoke) passed. User assets excluded from commit. Original master preserved.
