# 0.10.43-dev — Western Frontier native material and texture reconstruction

Local candidate based on 0.10.42 (published base e5eeb2f49e618bbcfd13c887ab1d11e26fca8ce4). Supports versioned UE4.14 (object version 508) monolithic editor Texture2D source packages with the existing bounded bulk/PNG validator. Reads the 40-byte scalar/color and 48-byte vector material inputs using the pre-514 FString layout and checks the serialized endpoint. Newer supported layouts remain unchanged. Skeletal LOD0 now preserves source material bindings and per-face material indices; the project scene material stage runs after native component reconstruction and applies explicit serialized component material overrides. No changes to underlying mesh coordinates or skinning.

Blender 4.2.4 strict acceptance with original Western Frontier: 230 unique bound mesh datablocks in Demonstration and 352 in Overview (582 across the two collections); 2,814 mesh objects, including 2,316 static actors, 462 foliage instances and 36 skeletal actors. Ten distinct referenced material graphs, no unresolved graph or missing image flags, no binding errors. All object material slots compared against source package paths and face material indices against native metadata. Five packed map image payloads and all slot package identities survived save/reopen; all 14 actual Texture2D source assets independently decoded and packed with exact PNG SHA-256 equality. Non-Texture2D packages under the texture directory excluded by export class. Materials are graph-imported/unverified, not pixel-identical Unreal rendering; translucency, lighting, engine-specific shader semantics and dynamic wind remain outside verified scope. Two /Engine/BasicShapes/Cube dependencies are absent; no invented replacement used. UE4.14 animation playback and full Goblin War Camp assembly are not newly tested.

Reproduce: set UE_WESTERN_PROJECT to project root, UE_WESTERN_OUTPUT to output blend path and UE_WESTERN_REPORT to JSON path; run `blender -b --python-exit-code 1 --python tests/blender_western_materials.py`. Source assets are not included in the checkpoint archive.
