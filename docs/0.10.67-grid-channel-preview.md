# 0.10.67-dev — legacy PNG material channel previews

The original ShooterSam `T_GridChecker_A` UE5 object version 1004 texture contains a PNG with an all-zero red channel, green checker mask and blue border mask. Its original `MF_ProcGrid` graph samples red for wire and green for checker. This is consistent with the older source PNG red/blue byte-order issue described by [UModel's author](https://www.gildor.org/smf/index.php?topic=6035.0); [Epic's ERGBFormat reference](https://dev.epicgames.com/documentation/unreal-engine/API/Runtime/ImageWrapper/ERGBFormat) distinguishes RGBA from FColor BGRA. Neither establishes pixel parity for this particular UE5.6 import.

The UE5 1004 BGRA8 PNG profile now constructs an explicit BGR-to-RGB node branch in partial-material previews. Original PNG bytes are unchanged, and strict materials still use metadata-only fallback. The alpha output remains directly connected to the original image. Explicit single-channel texture output slots no longer apply the duplicate serialized one-hot mask twice; conflicting slot/mask combinations are rejected. Modern raw textures and other PNG profiles are not swizzled.

The editor material revision changes batch and material-enabled repair fingerprints so old imports cannot silently reuse an outdated shader. Non-material repairs keep their old settings fingerprint. Existing edited objects are not replaced automatically.

Acceptance on Blender 4.2.4 Linux: original two grid material previews rendered and reopened. A separate top-view unlit 1024-square EXR evaluates the actual original Base Color node branch against a separate bilinear sampler of the original source mask. 40,560 major-wire and 898,704 interior pixels tested; median wire 0.0262410045 (source parameter 0.026241), median interior 0.1800000072 (source parameter 0.18). Source PNG SHA-256 remains `4ef26b0ae2b662d43f3d9fbc4aec1e843601c543cf37ed0489c02d7ef1e16021`. The 100cm primary and 20cm subgrid spacing comes from serialized instance parameters. Sampling boundary differences and Unreal runtime filtering are not verified. This is a source-derived channel interpretation preview, not a general legacy PNG conversion or Unreal reference-render equivalence.
