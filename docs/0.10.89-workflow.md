# Workflow and package parsing performance — 0.10.89-dev

A context-local LRU table cache is active only during a modern saved-level import or dependency audit. Cache entries include raw bytes and parsed tables; internal consumers must treat shared tables as read-only. Cache keys include file identity/size/mtime/ctime and sidecar stamps. Cache failures are not retained; source changes invalidate the entry. The 64 MiB budget includes conservative estimated table overhead, not measured total process RSS. Cache is emptied on exit, including exceptions. No persistent cache or cross-import source reuse. Source files are assumed stable during synchronous import; stat checks are not content hashes or an atomic filesystem snapshot.

The source actions report groups missing project/engine/mount/invalid packages, counts hard/soft incoming source references, lists unknown tables and labels the scope. It is not a count of visually missing objects. Blender UI shows a short selected-map summary and copyable text after analysis or one-click import. Modern one-click import reports stage timings and a synchronous progress indicator; mid-stage cancellation and background import remain unsupported.
