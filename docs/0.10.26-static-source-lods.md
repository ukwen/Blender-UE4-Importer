# 0.10.26-dev: native editor static meshes and source LODs

Material development frozen at 0.10.25. Native editor MeshDescription now preserves explicit edges, corner tangent vectors (axis-swapped), raw source binormal signs, original hard-edge flags and per-face source material indices when slot mapping is unambiguous. Stored tangent attributes are not a claim that Blender's renderer uses Unreal's original tangent basis. Static mesh import exposes All static source LODs, retaining original indices, source count and missing LODs; secondary objects start hidden. No generated LODs invented. Socket names retained as references, not transforms. Batch operator continues past failed files and reports counts. Default behavior remains first available source LOD. Cooked/stripped meshes, SpeedTree, collision, socket transforms, UE5 and generated render LODs remain unsupported or unverified. Existing shader translation unchanged.

Genuine user assets: Rope 32 vertices/60 triangles; Straw 12/20; Skydome 91/160; OarLock 71/142. Total 206 vertices, 382 triangles, 1146 corner tangent vectors and binormal signs, 333 true hard-edge flags, two UV channels each. Compared stored tangent/sign/hard-edge attributes directly with decoded source arrays. All four original meshes have one source LOD. Controlled multi-LOD binary header reused real Rope payload twice with explicit absent LOD1; retained indices 0 and 2. Actual batch operator imported two valid assets around one missing file. Save/reopen passed. 14 Python tests and 11 targeted Blender 4.2.4 regression scripts passed including genuine textured level, material binding and wind preview. No user assets committed. Next breadth priority: native skeletal mesh skeleton and skin weights, with cooked static mesh support still outstanding.
