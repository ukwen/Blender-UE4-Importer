# 0.10.25-dev: typed inherited parameter replay across detached layer snapshots

Extends 0.10.24's stable layer-GUID remapping to vector, texture and static switch parameters in addition to scalars. The ledger distinguishes association, index, case-insensitive name and type. Vector replay preserves RGBA including alpha. Texture replay requires an existing packed image and canonical source package; both typed target and texture-node counts must match. The existing sampler-binding path restores filtering, addressing and package metadata. A staged graph must remain complete after replay. Switch targets require supported unlinked selector sockets. Reordering with changed function packages, missing identities, removed or disabled overridden layers and prior unresolved records still fails closed. Parent-linked reconciliation is unsupported; this is detached snapshot support, not general Unreal inheritance equivalence.
