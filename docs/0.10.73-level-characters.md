# Saved skeletal characters in native level reconstruction

In the Unreal project sidebar, scan the original project, select a map and enable **Include Blueprint and skeletal components**. Reconstruct Static Geometry or run a selected-map batch. Native UE5.6 editor import now places supported saved character bodies in the same map collection, with source actor identity, local and world transforms, independent armatures, skin weights and original material references. The report separates reconstructed reference-pose bodies, geometry with unresolved material groups, and refused records. Batch reuse fingerprints the updated component profile and warns about unresolved characters. Existing tracked collections using the old component profile are not silently replaced.

The bounded profile requires exact level ownership, imported generated class, explicit CDO capsule/body pair and same-name owned saved components with explicit parent links. Instance transform fields take precedence over class defaults. Uniform positive capsule scaling is supported; nonuniform capsule scaling, arbitrary extra skeletal components, mixed static/skeletal actor chains, instance mesh overrides and socket/absolute transform modes are refused. No runtime actors are spawned. Native constructor defaults, animation Blueprint evaluation and runtime pose are outside the verified scope.

Original ShooterSam: seven enemy bodies (six MainLevel, one TestLevel), each 56,434 vertices and 155 bones. The five source polygon-group names do not match the five saved material names. The importer preserves separate unassigned group materials, the original material table and serialized overrides without guessing a slot mapping. The external Wraith Skeleton package is absent, so the original mesh's independently checked reference pose and skin weights are imported, but sockets are explicitly unavailable. The ordinary direct skeletal asset import remains strict by default. The side-scrolling NPC has no unique explicit skeletal asset and remains diagnostic; its static-component path is unchanged.

MainLevel's 1,976 saved static placements reference 227 missing packages; TestLevel's two environment meshes are missing engine dependencies. Thus the original fixture supports character placement validation, not complete visual scene reconstruction. The four previously tested template maps remain the static reconstruction baseline. This milestone does not claim a complete MainLevel or Unreal runtime fidelity.
