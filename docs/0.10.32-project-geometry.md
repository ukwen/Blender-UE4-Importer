# 0.10.32-dev: integrated native project geometry

Unreal project sidebar: choose .uproject, scan, select explicit cooked UE4.18 or 4.27 profile, optionally enter Content-relative subfolder, and click Import Native Geometry Folder. Class-based discovery (not asset filename prefixes) routes supported editor static, cooked static and cooked skeletal assets. Nongeometry packages are skipped, failures reported, newly created failed asset datablocks removed. Outputs a geometry-only inspection gallery with explicit X offsets, not original level placement. Per-package report persists as Blender Text. Supports up to 10000 candidate packages; external actor/object folders excluded. No automatic cooked version inference. Standalone skeletons, editor skeletal packages and unsupported layouts not imported by gallery. Static map resolver now routes split cooked geometry using the selected profile, caches success/failure, and preserves native cooked material slot metadata and face indices for the existing optional binder. Material shader development remains frozen.

Mixed test project contains genuine Matya cooked static and skeletal assets and genuine Goblin editor rope, copied/renamed, plus standalone skeleton and deliberately truncated static sidecar. Both profiles passed separately: three geometry assets, 1312 vertices, 1204 triangles, six bones, one skipped nongeometry and one failed package. Verified shared cached cooked mesh, source material indices, missing-material placeholder, failed dependency cache, folder traversal rejection, save/reopen report and skinned object. This is a test project assembled from genuine individual assets, not a complete original cooked level. Existing original partial Goblin textured level regression passed (562 static actors, three reconstructed meshes, 559 missing dependencies). Nine targeted Blender 4.2.4 executions and 14 Python tests passed. No user assets committed.
