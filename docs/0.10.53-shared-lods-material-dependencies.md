# Shared native LODs and cooked material dependency recovery

UE5.6 Quinn: opt-in direct skeletal import **All native LODs on one rig**, or project geometry batch **All skeletal LODs on one rig**. Three original LODs are decoded once, with one armature and shared source material slots. Select the armature, open Armature Data Properties > Unreal Native LODs, select LOD 0/1/2. Only one mesh is visible in viewport and render. Switching preserves the same Action. With a scene camera, enable Camera Distance mode and explicitly choose the two metre thresholds. Blender-native LOC_DIFF drivers select near/middle/far meshes; the camera target is the camera selected at setup, not automatically retargeted to subsequent camera changes. Manual buttons remove the add-on's own visibility drivers. This is not Unreal screen-size LOD evaluation. No change to existing single-LOD imports. Batch recovery detects changed LOD import settings and damaged group membership or skin binding.

Cooked UE5.0/5.4/5.5/5.6 gallery material inspection records typed texture references and, for supported instances, parent lineage. Exact available UE5.0/5.5 source textures are decoded and packed into reusable image datablocks, keyed by package identity, profile and all source sidecar hashes. Nodes preserve dependency scope and explicit instance parameter identity; outputs are deliberately unconnected because compiled shader graph and color semantics remain unresolved. Raw channels use Non-Color, not inferred sRGB or normal interpretation. Missing and unsupported references are reported. No new support for UE5 editor geometry, Nanite, IoStore, compressed animation, or unsupported cooked schemas.

Acceptance: `tests/blender_ue5_lod_group.py`, `tests/blender_ue5_lod_batch.py`, `tests/blender_cooked_material_dependencies.py`. Genuine Quinn 68,279 vertices/127,276 triangles, one 89-bone rig, two shared materials, one authored test Action; maximum deformation error 0.000486 mm. Six distance cases before and after reopen; stale settings and broken skin binding refused. Genuine Worm/modern cube: four packed source texture images; missing M_Cube_2 explicitly reported. Tests use original UAssetAPI and Matya reference assets; no replacement textures or generated geometry.
