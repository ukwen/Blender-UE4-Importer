# 0.10.79-dev — unified legacy commercial scene transfer

The existing **Import Complete Saved Level (Preview)** operator now dispatches the exact original uncompressed UE4 editor 508 / legacy -7 / licensee 0 profile to the existing legacy mesh, component, material and foliage readers, rather than the UE5-only scene reader. The archive is named 4.27 but its original map headers are 508; this does not establish general UE4.27 or UE5 instancing support. Legacy geometry imports are tagged with source map identity; the unified path rejects overlap with tagged prior geometry/full-scene imports. It includes the recursive source dependency report and strict gate, preserves the active user camera, and rolls back newly created Blender IDs on fatal errors. Directional light source transform and explicit intensity/color are preserved in an approximate Blender SUN preview. SkyLight is a marker, not environment lighting. Unrepresented direct PersistentLevel exports are reported. Raw legacy map imports without source ownership metadata are not covered by overlap detection.

Original fixture: existing Library Western Frontier pack, Demonstration and Overview maps. The existing foliage decoder provides 462 editable linked mesh instances, with two source mesh data blocks. The UE5 instance decoder remains unresolved. No gameplay, sky/fog, post-process, UE renderer parity, Windows or arbitrary package compatibility claim.

Run `UE_WESTERN_PROJECT=/path/to/PolygonWestFrontier UE_WESTERN_OUTPUT=/path/to/western.blend "$BLENDER" -b --factory-startup --python-exit-code 1 --python tests/blender_legacy_full_scene.py`. The source archive is a personal testing fixture, not bundled in the add-on.
