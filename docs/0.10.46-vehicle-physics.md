# 0.10.46-dev — native vehicle collision and automatic association

All 13 supplied Goblin War Camp vehicle PhysicsAssets are supported: 46 capsules, 69 convex hulls, 54 joints (108 frame anchors). Convex editor vertices and original bounds, empty index array, identity transform, collision flags and mass metadata are preserved. Face topology is reconstructed using a double-precision incremental hull, not imported from a cooked PhysX mesh. Nonidentity transforms and indexed convex payloads are refused. All 971 source support points tested; maximum plane error 3.62e-7 m; maximum bounds difference 0 m (Blender float coordinates); maximum posed matrix element difference 4.77e-7.

The geometry gallery now recognizes the exact companion SkeletalMeshEditorData export and optionally resolves physics package references against Content. Preview package and source rig identity are checked. Missing or unsupported physics does not erase successfully imported geometry; report includes per-mesh physics status and totals. Manual duplicate refusal and degenerate hull rejection tested. No filename-only search.

Real source assets staged at the serialized package paths for testing; no original Unreal assets included in the source ZIP. Vehicle gallery save/reopen passed in Blender 4.2.4. Prior 21 character/accessory/cape physics packages and 51 weighted vehicle articulation tests rerun successfully. Hulls and frames are bone-parented preview objects, not active collision or rigid-body constraints. Source material fidelity and full map regression not tested here.
