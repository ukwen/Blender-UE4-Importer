# 0.10.69-dev — procedural material coordinate and opacity previews

Editor material reconstruction preserves scalar Opacity/OpacityMask as labeled, unconnected data branches; no blend mode, first-person clipping, or runtime visibility is inferred. Explicit partial mode remains necessary for incomplete materials. Strict mode retains source metadata and disconnects the incomplete Principled shader. New bounded nodes include Constant2Vector, scalar Power, vector SphereMask with hardness below 100%, source UV Panner with constant speeds and nonfractional mode, and Time with an optional positive period. ParticleColor uses neutral editable RGB/alpha inputs, not simulated particle data. A shared material-local Time value is manually editable in seconds (not the Unreal clock). Explicit WorldPosition offset modes are preserved and rejected instead of silently interpreting them as default world position. A material revision invalidates prior material-enabled batch/repair fingerprints.

An independent radial formula compared with an isolated unlit render after Blender 4.2.4 save/reopen: 65,536 pixels, mean absolute error 0.00005631, p99 0.00068819. Three original `M_WP_Linkgun_Connection` panners tested with time 0 and 0.1 seconds; source UV scales 0.5, 1.0, 0.2 and speeds (0.2,-0.05), (-3,0), (-0.2,0.05). Worst p99 coordinate error 0.000286 in six interior-pixel tests, excluding plane boundaries and out-of-range RGB values. These are source-derived formula tests, not Unreal render comparisons. `M_MuzzleGlow` and `M_ImpactSmoke` still contain other unsupported particle expressions and their panners are not reconstructed end to end.
