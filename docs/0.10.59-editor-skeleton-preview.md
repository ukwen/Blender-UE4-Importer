# UE5.6 full editor USkeleton and authored animation previews (0.10.59-dev)

The native reference skeleton operator now reads the original tagged 1017 editor skeleton: named bones, parent indices, export names, double reference transforms, exact name/index map, named retarget reference transform arrays with serialized soft asset identities, and owned skeletal socket definitions. The original ShooterSam skeleton contains 161 bones, 5 sockets and two named 161-transform poses (Manny and Quinn). Socket definitions are preserved as data, not live attachments. The remaining 2,700 native bytes are not interpreted. The native armature carries an exact /Game package identity only when the file is located inside a project Content tree with a single descriptor. The 161-bone armature has no invented skin geometry.

The editor FK reader now validates additive mode, reference type, reference frame, self or external reference sequence, and per-animation retarget source soft identity and optional complete tagged reference-pose array. Two aim-offset clips have a source asset but no serialized per-clip reference pose; this absence is explicitly preserved. The Quinn named skeleton pose and a clip-local reference pose differ numerically, so neither is silently substituted for the other. Additive and retarget-source sequences require explicit authored-source-preview permission to create an Action. They are absolute authored FK samples only: no engine additive base-pose subtraction, runtime mesh-space offset accumulation, skeleton translation retarget mode, runtime retargeting, IK or blend graph is evaluated. Metadata is kept on each Action. Unreal case-insensitive FName identity is supported only with unambiguous mappings; strict package matching and the existing >=90% target overlap requirement for opted-in subsets remain.

ShooterSam inventory: 97/97 original AnimSequence assets decode (4,589 samples). 45 normal clips and 52 preview-only clips (34 retarget-source without additive, 18 additive including 3 with retarget-source metadata). Five remaining animation-related packages are not AnimSequence. Of the original sequences, 59 have 89, 32 have 159, and 6 have 161 transform controls; all names match the full reference skeleton case-insensitively. A full 161-track attack imports on the full skeleton without omissions; a 159-track walk retains two unanimated target reference bones. Simplified skinned meshes cannot receive absent corrective tracks and require explicit subset permission. A full reference armature is not a full character skin.

Blender 4.2.4 acceptance: three preview clips (fire, unarmed walk and aim-offset) on both textured simple mannequins, plus full skeleton attack and walk, 8 Actions. Checked source Euler world matrices and weighted positions; maximum skin difference 0.006206 mm. Preview opt-in rejection, 161-bone source operator, saved Action and reference pose/socket metadata tested; save/reopen passed. Actual engine additive and retarget playback needs engine-side evaluated reference data, and full map/Windows tests are not part of this milestone.
