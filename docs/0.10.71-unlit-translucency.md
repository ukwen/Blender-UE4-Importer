# 0.10.71-dev — bounded unlit translucent surface previews

Enable **Keep incomplete surface previews** when importing editor materials. For a saved UE5 material with explicit `MSM_Unlit`, a serialized single-model shading bitfield of 1, a surface domain, `BLEND_Translucent`, and successfully reconstructed EmissiveColor and scalar Opacity branches, the active Blender surface is an emission/transparent shader mix with clamped opacity. The original graph and scalar opacity remain editable. Unsupported base-property overrides, material attributes, explicit dynamic shading, refraction and displacement outputs block this preview. Strict mode remains metadata-only when the graph is partial. Masked, additive and lit blend equations are not inferred. Blender renderer approximation, not Unreal depth/sorting/transmission parity; no runtime particle simulation.

VectorParameter now decodes the RGB and separate R/G/B/A output slots, including matching repeated serialized masks, and preserves a separately editable scalar alpha parameter. The RGB node's alpha field is not the shader's alpha parameter; use the labeled scalar control. This restores both original SimpleGlow output branches. Material fingerprint revision 071 invalidates prior material-enabled import fingerprints.

Original ShooterSam acceptance: radial ramp and SimpleGlow use the new surface; Linkgun remains unresolved because its opacity output is vector-valued; masked Mannequin and additive LensFlare remain excluded.
