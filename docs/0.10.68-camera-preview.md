# 0.10.68-dev — saved UE5.6 spring-arm camera rig previews

Use the Unreal project sidebar, scan the original project, select a level, and click **Import UE5 Camera Rig Previews**. This is a separate collection and does not replace the active scene camera or existing geometry. Duplicate imports are refused. Remove the previous camera preview collection explicitly before reimporting.

The bounded reader validates level ownership, exact imported Blueprint package identity, generated class and class-default object, distinct saved component identities, component classes and serialized parent associations. It merges the saved instance transform fields over the corresponding class-owned component defaults. It accepts an explicit capsule root → SpringArmComponent → CameraComponent hierarchy and reconstructs a separate editable endpoint and Blender camera. Unknown, scaled, absolute, ambiguous or unsupported camera chains are refused and reported. Nonzero world-space target offset and explicit projection modes are not supported by this profile.

[Epic's spring arm API](https://dev.epicgames.com/documentation/unreal-engine/API/Runtime/Engine/USpringArmComponent) describes the target arm length as its natural length without collisions and socket offset as an offset at its end. This importer places the endpoint along the saved negative UE X axis plus the source socket offset, converted to Blender meters and axes. Runtime collisions, control rotation, lag, native constructor defaults, aspect-ratio constraints, and post-processing are not evaluated. Unserialized socket selection is treated as an explicit endpoint preview. Serialized FOV is used if present; otherwise 90 degrees horizontal is an editable preview default, not a recovered source value. Full source record metadata is retained on each camera.

Original ShooterSam evidence: all seven saved `FollowCamera` components (six MainLevel, one TestLevel) on `BP_EnemyCharacter`, with explicit 250 cm arm length, `(0,20,0)` cm socket offset and `(0,60,72.9832367)` cm boom offset. FOV was absent for all seven. Blender 4.2.4 acceptance verifies 28 preview objects, seven cameras, independent Unreal-axis position and orientation calculations, duplicate refusal, unchanged active user camera, save and reopen. Maximum preview position error 4.27162e-6 m; maximum forward vector error 2.15578e-7; maximum up vector error 1.79619e-7. These comparisons validate the stated preview formula, not an Unreal runtime-evaluated viewpoint.
