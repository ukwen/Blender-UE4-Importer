# 0.10.27-dev: native reference skeleton import

New File > Import > UE Reference Skeleton operator for explicitly selected cooked UE4.18/4.27 tagged split-package USkeleton profiles. Reads bounded header, class, export extent, tagged BoneTree and reference skeleton arrays, validates names, parents, transforms and name-index map. Creates editable armature with axis conversion and accumulated scale; original local transforms and accumulated world matrices retained as bone properties. Blender rigid rest matrices omit scale; shear and nonpositive scales are refused. Native skeletal mesh render buffers, skin weights, editor skeletal assets, animation, virtual bones, retarget settings, broader cooked profiles and exact rotational equivalence remain unverified. Not a complete skeletal mesh importer.

Genuine Matya-Uasset-Samples SK_Worm_Skeleton packages (4.18 and 4.27) have identical six-bone records. Parent names and joint origins compared against original raw SK_Worm.glb, maximum position error 1.1920928955078125e-07 m. Original scale 100 retained and accumulated. Wrong-class and truncated-sidecar refusal; save/reopen passed. 14 Python tests, four targeted existing Blender scripts (smoke, native_rope, raw_mesh, project_browser) and new reference skeleton regression passed in Blender 4.2.4. No source assets committed. Material checkpoint unchanged.
