# 0.10.64-dev — native UE5.6 lighting and scene markers

In Blender 4.2.4, open Viewport Sidebar → Unreal, select a `.uproject`, Scan Project, select a level, then **Import UE5 Lighting & Markers**. This is independent of Reconstruct Static Geometry: it creates its own collection, leaves existing geometry and scene world unchanged, supports Undo and refuses a duplicate source-map collection. To update a preview, explicitly remove the old lighting collection before importing again. Each collection retains an embedded JSON report with the original actor package, component, saved transforms, explicit source fields, and skipped/unsupported details. Do not combine the previews of several levels for rendering unless intended.

- Supported root light actors: DirectionalLight, PointLight, SpotLight. Only a matching owned root component in the saved PersistentLevel is accepted. Inline and World Partition external packages supported; attached components and absolute transforms rejected. Light direction maps UE +X to Blender -Z with the same handedness conversion as meshes.
- Original explicit intensity, color (including unused alpha), attenuation radius, source radius/length, cone angles, shadow flag, temperature flags and other supported scalar fields are preserved. Omitted native constructor defaults are not invented in metadata. Blender defaults fill missing preview fields. Brightness is deliberately a heuristic: sun intensity ×1, point/spot ×0.01, then the user-controlled preview multiplier. This is **not** a physical units conversion. Color is converted from sRGB FColor; angle and distance fields convert degrees/radians and centimeters/meters. Cone blend is a preview. Temperature, IES, source length, light functions, runtime shadow and exposure behavior remain unimplemented.
- PlayerStart and SkyLight, SkyAtmosphere, AtmosphericFog, ExponentialHeightFog and PostProcessVolume produce editable transform markers only. They do not implement spawn behavior, ambient illumination, fog, postprocessing, bounds or Unreal's rendering pipeline. No camera, world or render settings are overwritten.
- ShooterSam: all 146 saved root light actors and 29 markers from six supported levels imported; one unrelated redirector/non-World `.umap` refused. 511 explicit light properties checked. Position error 0.00382 mm, forward-vector difference 3.48e-7; independent matrix verification after reopen. Combined Third Person geometry and lighting test: 53 reconstructed meshes, two missing engine meshes, one directional light, five markers. Six-level audit file is a layout diagnostic, not one renderable level.
- 65 Python tests pass with original UE fixtures. Runtime renderer parity, StarterBundle dependencies, and all other 0.10.63 limitations remain open.
