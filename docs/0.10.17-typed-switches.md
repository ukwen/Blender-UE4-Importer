# 0.10.17-dev: typed numeric static switches

Conservative expression-width inference selects Blender FLOAT or VECTOR Mix sockets for supported float1/2/3 branches, with UE true=A and false=B ordering, unclamped results, scalar broadcast, literal static bool selectors and nested switches. Inference is limited to explicitly recognized expressions; unresolved widths and unsupported selectors retain the legacy preview with an Error marker. Float2 is represented using Blender's 3-component vector sockets; the extra component is padding, not a general float2 type system. Float4, material attributes, arbitrary function outputs, general expression-width inference, compile-time branch pruning and material layer permutations remain open. Constant3Vector socket assignment now normalizes input to three RGB values and adds alpha only for RGBA sockets.

Values include negatives and values above one. A case-insensitive override updated four typed nodes; save/reopen retained the selection. Unsupported float4 fixture is explicitly marked. 14 Python tests and all 19 Blender 4.2.4 scripts passed, including genuine Goblin textures and prior sampler, wind and scene tests.
