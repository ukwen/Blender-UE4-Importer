# 0.10.11-dev — base material property alignment and tagged global static switches

Corrected MapProperty reading order: key and value type names and optional property GUID precede the opaque map payload. The actual Goblin base material now reads all 21 top-level tagged properties to the terminator at byte 122306, including 16 expression references, 13 parameter groups, the 44-byte ParameterOverviewExpansion map and LightingGuid. Map entries themselves are not decoded. Original dependencies remain absent; no full shader visual reconstruction is claimed.

Tagged static parameter sets and variable-length StaticSwitchParameter arrays now read global boolean overrides, respect bOverride, inherit parent choices, match names case-insensitively, and reject unsupported scopes and component masks/layers. Static bool values and switch defaults are set on Blender nodes. The existing MixRGB representation selects a color branch at factor zero or one, with clamp disabled; this is not Unreal shader compilation or general typed scalar/vector/material-attribute permutation support. No real static-switch package acceptance yet: the tagged binary records and Blender switch graphs are controlled fixtures. Genuine base material parsing is tested separately. The fixture verifies differing record lengths, disabled overrides, sibling isolation, scope refusal and save/reopen. Run tests/blender_static_switches.py with UE_GOBLIN_BASE set to the supplied original base material.

Python 14/14 unit tests and all 13 Blender 4.2.4 regression scripts passed directly in the local runtime, including native texture, original rope, three genuine level meshes and prior material inheritance. No user asset files committed. Original master preserved. Remaining priorities: genuine complete material dependency chain, static permutation fidelity, UE5 import.
