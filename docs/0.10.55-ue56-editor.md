# UE5.6 editor source reconstruction

Fixture: ShooterSam original editor content, commit `1623ccdeac924ae0a1ec76289033e9ffa19d9f8a`. No cooked or synthetic geometry substituted. Table reader supports tested 1012–1018 tagged layouts; 861/864 packages inspected. Dependency decoder declines 15 soft-reference tails; hard references are retained. Three older 1004 packages not supported.

## Setup
The local source payload path requires a separate experimental decoder subprocess. On Linux x86_64 with a C/C++ compiler and SSE4.1, acquire the pinned independent source repositories:
- https://github.com/q3k/pyooz/tree/fde8c264d0bbcee36d9836cb1895c02861783d4e (GPL-3-or-later; inspect COPYING)
- https://github.com/BLAKE3-team/BLAKE3/tree/282d06646f0f47d90091e3413d0be2ba5bee3b1e (Apache-2.0/CC0)

Run `bash tools/build_editor_decoder.sh /path/to/pyooz /path/to/blake3/c /path/to/ue_editor_decode` then set `UE_EDITOR_PAYLOAD_DECODER` to the executable before launching Blender. No third-party code/binary is distributed in this source tree. Review third-party licensing before any distribution. This native decoder is experimental, not a security sandbox: use trusted original assets only. It has a size cap, profile validation, timeout, header CRC and full BLAKE3 verification. Windows build not validated. Only local trailer v2 payloads with the tested uncompressed/Oodle profile are supported; virtualized or referenced payloads are not retrieved.

## Blender workflow
In project browser choose the project descriptor and Geometry Folder scope, filter for desired assets, refresh and import. Modern editor 1016/1017 routing is automatic; choose 5.6 for cooked assets. Direct native skeletal mesh operator also accepts editor source LOD0. Map imports support root StaticMeshActors with explicitly serialized root components and external actor ownership. Material slots and per-object overrides retain exact package references; no shader graphs are claimed. Generated LODs, Blueprint/attached components, animation sequences, UEDELTA texture pixel decoding, other engine geometry, lighting, runtime and full MainLevel reconstruction remain unsupported. Missing references produce labelled placeholders. Full UE4 map regressions not repeated.

## Tests
Set `UE56_EDITOR_PROJECT` to the original .uproject and `UE_EDITOR_PAYLOAD_DECODER` as above. Set `UE56_EDITOR_OUTPUT` to an output blend path for each test. `python -m unittest discover -s tests -p 'test_*.py'` and Blender background scripts `tests/blender_ue56_editor_static.py`, `tests/blender_ue56_editor_skeletal.py`, `tests/blender_ue56_editor_maps.py`. Static 12/12: 7511 vertices, 14864 faces; skeletal Manny/Quinn: 89859 vertices, 179458 faces, 89 bones each, max deformation error 3.88e-7 m. Four maps: 343/348 root static actors (5 missing engine assets); 465 external actor packages. Batch reuse tested after save/reopen. Test poses are authored, not imported original animation clips.
