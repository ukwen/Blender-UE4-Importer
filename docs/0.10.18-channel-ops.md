# 0.10.18-dev: typed AppendVector and ComponentMask

Known-width AppendVector and ComponentMask expressions now use editable Blender groups with separately wired numeric channels. Nested append, float2/3 output, non-contiguous masks, scalar extraction and a four-component append carrier are implemented. A float4 carrier can feed a typed channel operation, but direct linking to a conventional socket is rejected and flagged. Unknown-width expressions fall back to the old incomplete graph marked Error. General float4 expressions, arbitrary serialized input swizzles, shader attribute structs and full material layers remain unsupported.

Six controlled importer-construction and Cycles CPU render cases passed (AB, ABC, GA mask of float4, RB mask of float3, B scalar, recombined masked vector). Maximum encoded EXR pixel error 2.384185793236071e-08. Save/reopen retained the four-component carrier. All 14 Python tests and 20 Blender 4.2.4 scripts passed, including the genuine Goblin production texture chain, native geometry and wind preview. No genuine asset-specific acceptance of the new channel expressions claimed. No original source assets committed. Master preserved.
