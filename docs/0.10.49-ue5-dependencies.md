# 0.10.49-dev — tagged UE5 dependency inventory and Blueprint ancestry

The new reader supports the supplied UE5 object-version 1012 monolithic tagged editor packages. Summary offsets bound the FName soft-package table, top-level asset plus subobject path table, and per-export dependency index arrays. Subobject references within the current package are reported, not treated as additional files. Hard and soft provenance is separated in the preflight report. Layout reference: supplied MIT UAssetAPI `UAsset.cs` ReadHeader/DependsMap/SoftPackageReferenceList and `SoftObjectPropertyData.cs` FSoftObjectPath. Unsupported versions, cooked sidecars and unversioned properties are not claimed. This does not recover runtime dependencies or execute Blueprint bytecode.

Blueprint ancestry resolves explicit package/class pairs, with bounded depth and cycle refusal. Existing child declarations win, including explicit null. A missing child mesh field may inherit only from the same explicitly associated CDO template/class. Unproven inherited SCS nodes and InheritableComponentHandler overrides are not synthesized. The resolved package/class chain and mesh declaration provenance are stored on map anchors. The existing body transform and socket reconstruction remain authoritative.

The new **Selected map geometry** batch scope uses the selected map's known transitive package dependencies, filters to known geometry exports, and supports checked-job selection. Results are an inspection gallery, not a replacement for level import. Reopening the file and importing the same packages through Geometry folder reuses their verified session. The whole-project fingerprint remains conservative.

Acceptance in Blender 4.2.4: 15 real Goblin character class chains (11 UE5 children, four UE4 children, one shared UE4 parent); 11 UE5 packages, 22 self-package soft-object paths, 320 dependency rows and 189 signed package indices. Four corrupt copy tests rejected invalid table data; a controlled modified copy verifies external soft package extraction. No genuine external soft-package reference occurred in these 11 UE5 samples. Selected map geometry filter found 17 character mesh jobs, imported two checked jobs, saved/reopened and reused both via Geometry folder. Full Goblin assembly regression: 15 bodies, 37 accessory placements (three geometry present, 34 missing), 300 sockets and 45 animation Actions; saved/reopened. Host-independent tests: 17 passed, four skipped. Smoke registration passed.

Remaining scope: additional UE5 object versions, generic inherited SCS override records, soft-reference UTF8 subpath variants, runtime Blueprint and asset-registry dependencies, UE5 native mesh formats, and missing Goblin source assets. No new Unreal assets redistributed.
