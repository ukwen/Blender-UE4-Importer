# 0.10.15-dev: texture coordinate and sampler semantics

The native mesh importer flips V. The texture expression graph now converts explicit UVMap coordinates to Unreal top-left convention and applies U/V tiling there, then converts explicit linked texture coordinates back at sampling. Default Texture2D samples share an explicit UV0 node rather than relying on active render UV. Texture editor and UModel fallback metadata retain both address axes; shared sampler overrides respected; wrap/repeat, clamp/extend and mirror matched. Mixed axes and unmirror flags explicitly mark the graph incomplete; filtering based on nearest flag, not general engine sampler-state fidelity. Other UV-producing expressions and non-UV0 normal-map tangent selection still require acceptance.
