# 0.10.81 — Opt-in saved sky preview

UE5.6 original levels with one enabled saved directional light, one real-time-capture SkyLight and one SkyAtmosphere receive a separate editable Nishita world. Sun direction is derived from the saved light rotation in Blender coordinates. Sun disc disabled to avoid duplicating the existing directional light. Explicitly select the imported map and press Apply Selected Level Sky Preview. Import never replaces the scene world automatically. Undo or select the prior world to restore it. The sky model, default strength and intensity are Blender approximations, not measured Unreal radiance. Sky color, hemisphere policy, cloud/shadow effects, captured cubemaps and fog rendering are not reproduced. MainLevel's AtmosphericFog profile and legacy skies remain unsupported. Saved fog records are preserved in the report, including four explicit density values.

Actual Blender 4.2.4 Linux test: five original map sky worlds, one integrated ThirdPerson scene plus four world-only original record tests, one rejected MainLevel. Source direction compared to imported sun +Z within 6.144e-8 unit-vector distance; explicit activation, original world preservation, rollback and save/reopen passed. CPU Cycles 32x32, 4 samples sky-only EXR render: finite nonnegative RGB 0.982358–8.879155. This demonstrates radiance, not ground illumination or Unreal parity. Run `tests/blender_ue56_environment_preview.py` then `tests/blender_ue56_sky_render.py` with the same UE56_EDITOR_OUTPUT path. EEVEE and Windows not tested. No additional assets acquired.
