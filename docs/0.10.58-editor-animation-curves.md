# UE5.6 editor animation extension (0.10.58-dev)

The bounded direct FK reader now accepts variable transform control counts (1–512, with the existing 250,000 sample limit), and explicit same-skeleton subset application requires at least 90% of target bone names. The original 159/161-control source clips contain corrective or auxiliary bones not present in the 89-bone simple mannequins. Subset application omits these explicitly, and unanimated target bones retain their local reference transforms. This is not runtime retargeting or reconstruction of the omitted bones.

Sparse scalar channels validate ordered in-range keys, finite values, stride, default and unweighted interpolation modes. The source scalar key/tangent data is preserved as JSON on the Action; generated object custom-property F-curves reproduce linear, constant and unweighted cubic Hermite segments. Extrapolation is constant outside the authored key span, not a claim of all Unreal curve semantics. Scalar values retain their source units; IK or other runtime logic is not evaluated. ControlChannelMap, notify/sync metadata and duplicate RawCurveData/AttributeCurves are not executed. Generated property collisions with unrelated data are refused. Existing generated controls can be reused by other Actions; unkeyed controls may retain previous values when switching Actions. The source RateScale is preserved and an explicit operator option applies it to Action timing; by default authored sample timing remains unchanged.

Original ShooterSam inventory: 102 mannequin animation-related packages, 97 sequences; 45 source sequences decoded (2,003 samples), versus 29 (1,376 samples) previously. 52 additive/retarget-source sequences remain unsupported and 5 packages are not AnimSequence roots. Five new clip types applied to Manny and Quinn: reload, jump landing, 2x fall loop, 159-control jump and 161-control attack. Ten editable Actions persisted through save/reopen, compared against independent source Euler matrices and weighted mesh positions. Max measured skinning difference 0.009324 mm; max scalar segment comparison error 7.63e-6 source units. This verifies source-data translation, not UE runtime playback parity.

Run tests/blender_ue56_editor_animation_extended.py with UE56_EDITOR_PROJECT, UE56_ANIM_INPUT and UE56_ANIM_OUTPUT. The original 0.10.57 acceptance remains applicable. Full map and Windows decoder tests not performed for this change.
