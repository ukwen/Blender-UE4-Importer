# 0.10.16-dev: independent sampler addressing and explicit tangent basis

Mixed U/V modes use an owned per-sample node group with mirror folding and half-texel clamping for non-wrapped axes. The wrapped axis retains Blender's repeat sampler, including bilinear seam blending. Texture replacement restores the original coordinate connection before updating the addressing stage, and explicit coordinate links route through the helper. Base-level nearest/linear behavior is implemented; mip and anisotropic equivalence are not established. Tangent-space normal maps explicitly name UV0, the assumed mesh tangent basis for the tested assets; world-space normals are marked unsupported. Imported Unreal tangent vectors and full MikkTSpace parity have not been independently validated.

Five controlled Cycles CPU render assertions passed: wrap/clamp, bilinear seam, mirror/wrap, replacement, and UV0 tangent normal with rotated active UV1. Four sampled color cases had zero error; maximum encoded normal error 7.152557368605983e-08. Both genuine Goblin material instances reopened with UV0 normal maps and three packed 4096x4096 images each. 14 Python unit tests, 17 prior Blender scripts and the new sampler/normal regression passed in Blender 4.2.4. Set UE_UV_SCENE to the expanded fixture output from blender_goblin_textured.py for the new test. No project assets committed. Missing sky and engine wind dependencies, generalized shader permutations, complete tangent equivalence and reference-render visual acceptance remain open.
