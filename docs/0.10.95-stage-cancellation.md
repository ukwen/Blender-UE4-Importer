# 0.10.95-dev — cooperative cancellation and source-backed diagnostics

The primary Import Selected Level and Import Checked Levels buttons invoke modal reconstruction for supported UE5.6 editor maps. All Blender data creation stays on the main thread. Static actors yield every 32 placements, Blueprint components every 16 actors, material binding every 32 objects with the same operation-local material cache; read-only and major scene stages also yield. The table cache context is restored before each yield, retained only by the transaction, and cleared on completion or close. Synchronous callers drain the same generator. A cancelled modern level removes all newly owned IDs and restores existing scene camera/world; a checked level set also rolls back all previously staged levels. No other edits are allowed during the modal transaction. This is not arbitrary mid-function interruption: native payload subprocess, individual material graph, character and terrain stages, dependency scans and legacy import are still synchronous. Escape is processed at the next safe boundary. Elapsed wall time includes event-loop gaps.

Material diagnostics preserve explicit package identity, known hard dependency closure, unknown tables, original translation issues and per-use status. Mesh slots, saved decal projectors and landscape material references are distinguished; presence or recovery is not proof of rendering support. Soft/plugin references stay in the general source audit. Selected-level Source Actions and scene transfer JSON expose this information; no replacement textures or inferred shaders are created.
