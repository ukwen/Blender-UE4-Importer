# One-operation saved level transfer (preview)

In Blender's Unreal Project panel, choose the original `.uproject`, Scan, select a map, optionally enable partial material previews, then **Import Complete Saved Level (Preview)**. The operation constructs a single level collection containing editable geometry/characters and supported light and camera previews. It binds exact source material references, retains unsupported records, and links matching saved spring-arm camera roots to the corresponding skeletal actor only when their original identities and world transforms agree. The active user camera is not replaced.

The scene transfer JSON Text datablock includes per-stage reports, material statuses, inventory of direct serialized PersistentLevel exports and representation counts. These counts overlap, distinguish markers from meshes, and do not imply runtime scene completeness. A stage with no supported records is reported rather than failing. A fatal stage exception rolls back newly created Blender IDs. An existing full or separate native stage blocks the full operation; an existing full scene blocks another native geometry import. No automatic replacement of user edits. Select a different level or explicitly remove the old collection before retrying. No cross-level streaming, animation assignment, terrain/foliage parity, sky/fog/postprocess evaluation or engine lighting equivalence is claimed.

Acceptance: `tests/blender_ue56_full_scene.py` exercises the original ShooterSam ThirdPerson and MyStuff/Maps/TestLevel via the actual operator, linked camera motion, existing camera protection, duplicate refusal, injected late-stage rollback and save/reopen. ThirdPerson has 53 native meshes, two unresolved static anchors, one light and five markers. TestLevel has a saved skeletal body with unresolved original slots, two missing environment meshes, one light and one character-linked camera preview. New project candidate binaries have been sampled through GitHub but no complete replacement project has been acquired. The original missing source dependencies remain a blocker to complete visual scene validation.
