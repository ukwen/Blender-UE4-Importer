# 0.10.75-dev — scene dependency qualification

Select a project and level, then click **Analyze Level Dependencies**. The JSON Text datablock records the selected map, its discovered external actor and external object packages, and a bounded transitive closure of readable hard and soft package references. It identifies missing project and engine packages, unsupported mounts, invalid or ambiguous identities, and unknown hard/soft table formats. Available engine packages are recursively inspected if the optional `UNREAL_ENGINE_ROOT` environment setting or existing Windows registry discovery resolves their original files. No surrogate meshes are generated.

Enable **Require resolved source dependencies** to refuse a scene transfer before creating any objects, materials, images or collections if there are known unresolved references or unreadable dependency tables. The default remains permissive for incomplete projects; the same audit is embedded in the full scene report. Conservative package references may include editor/gameplay assets that are not needed for visual reconstruction. Passing this check does not prove runtime dependencies, actor coverage, shader accuracy, or full scene fidelity. Unknown formats and missing mounts remain explicit. The reader does not execute Blueprint or stream missing external data; external object files are inspected, not automatically converted into geometry.

Original ShooterSam UE5.6 acceptance audits six levels, confirms strict refusal without mutation, and runs unified transfers for Combat, Platforming and SideScrolling with 127, 134 and 96 mesh objects respectively. Save/reopen and persisted coverage reports pass. Existing ThirdPerson/TestLevel scene regression is retained. Source dependencies remain incomplete (including StarterBundle, engine content and plugin mounts); no new complete external project archive has been obtained. Windows not revalidated.
