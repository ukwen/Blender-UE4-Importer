# 0.10.50-dev — bounded UE5.0 cooked geometry

## Supported profile

Explicit `5.0` profile in the native static, skeletal, reference skeleton import menus and project geometry browser. Tested against the Matya UAsset Samples genuine 5.0 split packages, not against arbitrary UE5 editor or IoStore assets. The unversioned package header does not encode a usable object version; the selected profile is explicit. The native readers enforce the tested unversioned fragment layouts and table/sidecar boundaries and reject unsupported layouts. No buffer-offset search is used. Static render geometry is the ordinary indexed fallback mesh; Nanite clusters, additional LODs, cloth, high precision tangents, nonempty external static bulk payloads and arbitrary unversioned property schemas are not supported. The static reader consumes bounded opaque render metadata, not collision data. Some fixed-schema property data is not interpreted.

The split import table reader recognizes all eight genuine UE5.0 test packages and discovers their package references without claiming soft or runtime dependency coverage. The two native meshes retain their original material slot and package identity. Existing UE5.0 cooked texture loading decodes all three source textures; the cooked material shader graph is not translated and the mesh slots remain unresolved. The gallery test packs the textures separately for inspection, not as a reconstructed material.

## Acceptance (Blender 4.2.4 LTS)

- Static and skinned meshes: 640 vertices / 572 triangles each; exact positions, triangle indices, slot assignments, normals, tangents and signs compared to the genuine UE4.27 versions. UV difference <= 0.00048828125. Source skin weights exactly equal UE4.27.
- Six-bone reference skeleton; source mesh/reference asset transforms agree within 2.23e-16, and UE4.27 transforms differ by less than 2.72e-8 in native units.
- Original raw GLB skeletal position error 3.654e-7 m; weight difference <= 1/255 + 1e-6; UV difference 0.000234366. Actual Blender bone-driven mesh deformation: 352 vertices moved, max error 2.666e-7 m versus independent skin calculation; maximum motion 0.4542 m. Authored test pose Action persisted across save/reopen. This is not imported native animation.
- Eight known split packages, six available dependency targets, two gallery jobs, both reused after reopening without additional objects. Separate reference-skeleton and static import operators passed. Three source textures packed and reopened.
- 26 Python tests passed (including genuine texture samples and malformed geometry rejection). Native UE4.18/4.27 static, UE4.27 skeletal, nine cooked textures across 4.18/4.27/5.0 and Blender registration regressions passed. Full Western Frontier and Goblin map regressions were not repeated this milestone.

## Reproduction

Set `MATYA_ASSETS` to the extracted Matya-Uasset-Samples-main directory and `PYTHONPATH` to this source root. Run `python -m unittest discover -s tests -p 'test_*.py'`.

Run Blender 4.2.4 headless with `tests/blender_ue5_cooked_geometry.py`; set `UE5_COOKED_PROJECT` to a disposable directory, `UE5_COOKED_OUTPUT` to a `.blend` path and `UE5_COOKED_REPORT` to a `.json` path. The test makes a minimal project descriptor around copies of genuine sample packages, not a native UE5 level. Run `tests/blender_native_skeletal.py` with `UE_SKIN_PROFILE=5.0` and `UE_SKIN_OUTPUT` to reproduce the GLB and deformation acceptance.
