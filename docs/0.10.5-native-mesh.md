# 0.10.5-dev — first native legacy MeshDescription mesh

A user-supplied UE4 editor StaticMesh package, SM_Prop_Rope_01.uasset, was imported through ImportMeshUAsset with Blender 4.2.4. Native zlib payload decoded with the existing bulk reader. New bounded sequential legacy MeshDescription parser validates counts, allocation masks, attribute arrays, references and full payload consumption. No fixed fixture offsets or third-party decoder code are used.

Observed output: 32 vertices, 90 edges, 60 triangles, 180 corners, 2 UV layers, corner colors, split normals, source material slot Goblin_01_A219. Normal-to-polygon dot range 0.6163573–0.9255010, all 180 positive. Dimensions (m): 0.07311569, 0.08440446, 0.07295803. Saved and reopened successfully in a separate Blender process. With materials enabled, the missing parent dependency results in a marked unresolved material placeholder, not a reconstructed material. Geometry is original native geometry; no visual comparison to Unreal. Asset not committed.

The decoder is limited to the observed legacy editor layout: zero-length polygon perimeter records, separate triangle records, supported attribute serialization. Other layouts, cooked assets and UE5 are not accepted. Multi-slot and multi-LOD cases remain unverified; first decoded LOD retained. Tangent/crease attributes parsed but not transferred. Six resolver tests and original addon smoke test passed on local source. The latest branch is patched from its current head; the older uploaded checkout is not a byte-identical full current branch.

To reproduce, load the original rope package with ImportMeshUAsset(path, import_materials=False). Check geometry counts, UVs, corner normals, source slots, then save/reopen. No original assets redistributed. Master untouched.
