# Source recovery, cancellation and memory — 0.10.90-dev

Select a saved map and an original asset recovery directory outside project Content. Locate Missing Original Packages scans a bounded directory tree (10,000 directories and asset files), skips symlink candidates and project Content, matches the serialized package name, validates the native monolithic editor 1016/1017 table extents and primary asset export, and hashes the candidate. Duplicate candidates are ambiguous even if byte-identical. Only missing `/Game/` assets qualify; no split/cooked, engine/plugin, map, external actor/object restoration or filename-only substitution. The text plan is read-only in the sense of no filesystem changes; a new plan is recomputed before restoration and must exactly match the reviewed plan. The restore operator asks for confirmation on interactive invoke. It copies bytes into a temporary file in the destination directory, verifies SHA-256, and publishes via exclusive hard link without overwriting any existing file, sidecar or map. Ordinary failures roll back files created by the operation and empty newly created directories. Filesystems without hard-link support fail closed; this is not a crash-recovery journal or hostile concurrent-filesystem protection. Filesystem restoration is not Blender Undo. This validates source identity and tables, not arbitrary asset payload fidelity. Reaudit after restore; new missing transitive refs may appear. No source acquisition or modification of recovery-folder originals.

Select Recoverable Mesh Anchors selects visible, unrepaired native missing anchors in the selected map whose exact package identity is now available. The existing repair operator still checks saved actor/slot associations and decoded geometry before creating children. New repair overlays are nested in their original geometry collection so map switching does not leak repaired objects into other maps. Original direct collection membership, reports and user edits are preserved; historical reports are not rewritten to certify edited scene content. Previous root-linked overlays are not migrated automatically.

A configurable 0–256 MiB package-cache budget (64 default, zero disables) applies to modern one-click import, dependency analysis and checked-level import. Linux ru_maxrss is total process high-water including startup and scene data, not a cache-only allocation, and one run per setting does not establish portability or statistical significance. The cache trades additional memory for fewer parses. Low-memory UI mode verified in two-map regression.
