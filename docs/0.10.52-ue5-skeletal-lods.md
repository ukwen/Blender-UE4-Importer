# UE5.6 native skeletal mesh LODs

Fixture: original UAssetAPI Tests/TestAssets/TestUE5_6/BpThirdPerson/SKM_Quinn_Simple split asset. Explicit unversioned property fragment schema, three inline render LODs, 89 double-precision reference bones, two material sections, fixed 4/8 influence 8-bit local indices and weights, one UV channel. All three LOD buffers are parsed and validated before returning the selected LOD. No offset search, no fallback conversion. Original material and skeleton package identities retained.

Blender 4.2.4 acceptance: all 68,279 vertex positions and group weights, all 127,276 triangle indices and material indices, 89 bones per rig, actual non-root bone pose compared against independent weighted matrix sums, max error 0.000361 mm; neutral pose recovery exactly zero. LOD0 project batch and two direct selected-LOD imports, save/reopen and duplicate-free LOD0 reuse. 33 Python tests passed. Registration smoke passed. Full map and animation regressions not repeated in this milestone.

Unsupported: general UE5.6 schemas, variable/16-bit weights, external render LODs, cloth, ray tracing, separate modern skeleton packages, physics simulation, native modern editor formats and compiled material shaders. No automatic LOD switching. Use individual LOD selection; gallery imports LOD0 only. Source texture dependencies absent. Native geometry is not visual parity with Unreal Engine.
