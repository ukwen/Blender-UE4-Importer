# UE5.6 editor FK animation, 0.10.57-dev

The native animation operator now reads the tested tagged 1017 monolithic editor AnimSequence, AnimationSequencerDataModel and single owned MovieScene FK control-rig parameter track/section. It verifies ownership, class identity, populated model, active controls, direct mode, frame rate, range, default easing and blend type, dense 30 Hz sample times and constant channels, finite transforms and positive scales. Source Euler channels are converted using Unreal FRotator signs. The existing native bone matrix conversion generates editable quaternion Actions at the target Blender scene rate.

The ShooterSam audit enumerated 102 assets in the mannequin Anims tree, including 97 AnimSequence assets. 29 sequences passed (1,376 source frames); 68 sequences were rejected for additive or retarget-source asset fields (52), other control counts (9), extra section channels (6), and nonunit rate scale (1). Five other assets were rejected as non-AnimSequence. Original source retarget names and root motion/lock flags are preserved as Action metadata, not executed. Same skeleton package and exact bone names are required, except when an explicit subset is enabled. For some original sequences, two weapon controls are absent in the source meshes and the two auxiliary mesh bones remain at their reference local poses. No runtime retargeting, root extraction, interpolation tangents, curves, notifies, additive animation or compressed runtime tracks are reconstructed. The supported source samples are not an Unreal engine playback equivalence claim.

Blender 4.2.4 acceptance: original MM_Idle (228 samples), MM_Rifle_Equip (51) and MF_Rifle_Walk_Fwd_Left (47), applied to both native textured mannequin rigs, 6 editable Actions. Independent byte reads and Euler-matrix composition checked five original sample poses per sequence on all 89 bones and every vertex of both meshes; maximum skinning difference 0.006331 mm. Save/reopen preserved all six Actions and active walking clips. Existing animation and constraints are refused. The host-independent test suite includes dense/constant channels, malformed channel rejection, Euler convention and three genuine sequence reads.

Run the Blender acceptance using UE56_EDITOR_PROJECT, UE56_ANIM_INPUT (the 0.10.56 textured scene) and UE56_ANIM_OUTPUT. Full UE4/UE5 map regressions were not repeated. The operator remains deliberately scoped to the original verified profile.
