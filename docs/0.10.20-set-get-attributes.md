# 0.10.20-dev: GUID-based Set and Get Material Attributes

Previous 0.10.19 accepted Make, Break, Blend and eight editable surface fields. This change supports Set and Get using the original attribute GUIDs and serialized order. Exact-width tagged GUID and ExpressionInput array layouts (including empty GUID arrays) are supported for the specified UE4 layout. GUID words are interpreted as four little-endian uint32 values rather than UUID text order. Reference: UE4.25.3 attribute identifiers documented at https://shuntaendo.hatenablog.com/entry/2020/11/04/230000 and Epic's Material Attributes Expressions documentation. Eight known fields only; unknown/duplicate identifiers and unresolved explicit Set inputs mark the graph incomplete. Get output 0 passes the supported bundle; selected individual outputs follow serialized order. No full material-layer stack, material-attribute function interface, unknown fields or unconnected Set defaults accepted.

Controlled binary arrays and real Blender node construction verified. Six Cycles CPU field renders matched expected values with maximum error 2.384185793236071e-08; original bundle unchanged; save/reopen passed. 14 Python tests and 22 Blender 4.2.4 regression scripts passed, including earlier genuine Goblin material and geometry tests. New Set/Get graphs are controlled fixtures, not production layered assets. No user assets committed.
