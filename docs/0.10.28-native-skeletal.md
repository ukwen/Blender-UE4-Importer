# 0.10.28-dev: native UE4.18 cooked skeletal render meshes

Bounded reader for the tagged editor-filtered split-package UE4.18 profile. Parse package tables, known property tags, bounds, material slots, embedded reference skeleton, one render LOD, section bone palettes, indices, packed tangent/normal data, half/full UVs, fixed 8-bit weight buffers and adjacency/trailer sequentially. No byte scanning. Unsupported profiles, unexpected properties, nonmatching section bounds, malformed palettes, cloth layouts, invalid weights and trailing data fail before Blender object creation. Geometry, original render/import vertex indices, UVs, source tangent/sign attributes, placeholder material slots, named vertex groups and linear Armature modifier are editable. Uses shared reference armature conversion. This is not a general animation or material importer, nor a guarantee of original tangent-space rendering. References consulted: Matya Blender-Uasset-Addon format descriptions and Matya-Uasset-Samples genuine assets (https://github.com/matyalatte/Matya-Uasset-Samples); no fixture assets committed.

Genuine UE4.18 SK_Worm: 640 render vertices, 572 triangles, 6 bones, all 640 vertices have weights totaling 255. Against original raw GLB, nearest-position maximum 3.6537723210891136e-07 m, maximum per-vertex minimum matching weight error 0.0039128600382337675 (below 1/255), UV error 0.00045228004455566406. Reference comparison matches source positions and checks weights/UVs at matching positions, not a full topology or render equivalence claim. Real Blender 4.2.4 pose test: 352 moved vertices, maximum motion 0.4542032375385503 m, maximum difference against explicit weighted Blender pose/rest transforms 2.6656007498500226e-07 m. Neutral recovery, editable authored test action, save/reopen and frame-20 deformation verified. No Unreal source animation claimed. 14 Python tests and 6 targeted Blender scripts (native skeletal, reference skeleton, smoke, raw mesh, project browser, native rope) passed. Wrong class, UE4.27 layout and truncated sidecar rejected. Future priorities: modern cooked UE4.27/UE5 skeletal buffers, broader section/LOD layouts, morphs and native animation sequences.
