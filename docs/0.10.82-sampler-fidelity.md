# UE5 editor texture sampling fidelity — 0.10.82-dev

Implicit UE texture coordinates now bind named UV0 explicitly (rather than Blender's active UV map). Explicit coordinate expressions retain their UE-to-Blender V conversion. The editor graph reuses the legacy independent-axis address helper, with base-level nearest/linear scope and explicit warnings for mixed addressing and world-group filtering. Packed original image bytes are unchanged. Material cache revision is bumped to block reuse of obsolete converted graphs.

For the bounded direct UEDELTA non-color normal texture → tangent-space Normal output with implicit UV0, explicitly use UV0 for the Blender Normal Map basis and invert the source green component unless the serialized texture requests a green-channel flip. This is a source-art convention preview, not a complete runtime normal decoder; arbitrary graph arithmetic, world-space normals, other texture profiles, BC5 runtime Z reconstruction, mip/anisotropic filtering, Unreal tangent basis and engine rendering remain unverified. No claim of exact Unreal material appearance.
