# 0.10.22-dev: bounded default material layer stacks and scoped overrides

Supports a single default stack with explicit tagged Layers, Blends and LayerStates arrays, an enabled background and up to 32 layers. Special layer and blend function exports reuse the material-attribute interface. Active layers get separate group instances; blend pins follow distinct SortPriority values. Disabled layers retain original indices, and null active blend references mean opaque replacement. Optional layer inputs receive the explicit base attribute bundle, not the preceding layer. Missing preview defaults, missing or disabled background, multiple stacks, function instances, non-tagged/custom layouts and instance-level topology overrides remain unsupported. Layer and blend scoped overrides use association, index, case-insensitive name and parameter type. Numeric enum values 0/1/2 mean layer/blend/global. Topology overrides or unreadable static parameter sets block scoped overrides for descendants rather than silently targeting the wrong indices. Scope routing is implemented for existing override kinds; only scalar scope routing has new render acceptance.

References: Epic UE4.27 Material Layers, MaterialLayersFunctions and MaterialParameterInfo documentation, MaterialParameterAssociation enum documentation, and public UE4.23 MaterialExpressions.cpp RebuildLayerGraph/ValidateLayerConfiguration behavior.
