# Native saved brush operands — 0.10.86-dev

The bounded UE5.6 editor 1016/1017 path follows explicit inline PersistentLevel Brush → owned BrushComponent and Model → referenced owned Polys exports. The tested Model native tail is 158 bytes, with a Polys reference at byte 102. The tested FPolys tail starts with a zero int32 and polygon count, then float32 base/normal/texture basis vectors, explicit variable-length vertex arrays, and 76 opaque bytes after each array. Full extents, finite coordinates, distinct vertices, nondegenerate planar polygons and saved plane normals are checked. No byte scanning or guessed geometry. A texture base need not be coplanar: 49 original polygons have nonzero base-plane offsets, preserved as metadata. Triangle and quad source faces are retained; source coordinates are converted using the existing centimetre/axis conversion, with exact local welding and winding consistent with the saved normal. Opaque post-array bytes are preserved, not interpreted as a complete material mapping.

The full-scene importer adds a non-rendering wire collection for explicit Brush_Add and Brush_Subtract actors, with source identity, payload SHA-256, raw polygon records and saved transforms. Coverage explicitly reports brush_operand_guide; counts.meshes excludes these objects. Untyped/editor builder brushes and volume subclasses are not reconstructed. No compiled BSP CSG, final visible surfaces, external brush payloads, collision or UV/material projection claims. This keeps subtractive operands from incorrectly appearing as solid visible scene geometry.

Original source evidence: MainLevel 45 additive brushes (360 unique per-object vertices, 271 faces), TestLevel 4 additive and 4 subtractive (64 vertices, 48 faces), zero typed-brush skips. Combined 53 operands, 424 vertices, 319 polygons, 1,274 corners. Two untyped brushes excluded in these maps; four other original maps each have an untyped builder. Twenty-six compiled ModelComponent exports across MainLevel and TestLevel remain unsupported. Actual Blender acceptance independently walks the source byte offsets, verifies local vertices, saved normals, translation, scale, rotation and world positions, checks render exclusion and exact reopened matrices. MainLevel brush-only stage plus integrated TestLevel import; full-scene and checked-level tests independently rerun. This is not a full render-equivalent scene reconstruction.
