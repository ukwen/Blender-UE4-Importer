# 0.10.37-dev: genuine character rigs and explicit compatible accessory binding

UE4.27 editor skeletal meshes retain original Skeleton package references on the resulting mesh and armature. In Object mode select one native accessory mesh and make the target armature active, then F3 > UE Bind Compatible Skeletal Accessory. The operation verifies skeleton package identity, native bone hierarchy and source and Blender reference matrices, identity accessory local transform, and unmodified skin binding. Reparents in shared reference mesh space, redirects the armature modifier, retains the source armature, and supports Blender undo. Not an automatic Blueprint placement or general retargeting tool. Socket transforms, inherited component offsets, material binding and original animation remain incomplete.

Genuine supplied 15 bodies and four skinned accessories: all 19 decoded and built, 151963 vertices, 52013 triangles, 718 bones, no removed triangles. Weight/group equality, four stored UVs, colors, pose/neutral and save/reopen verified. Maximum explicit weighted skin calculation error 4.139870314767675e-07 m. Two Blueprint-referenced hood/body pairings (Archer Female Hood_01, Ranger Hood_03) bound through the registered operator, compared to separately posed source accessory armature at two controlled poses each, zero evaluated vertex deviation. Both retain binding after reopen. King_02 and Troll_01 deliberately rejected for differing reference transforms despite shared package. No original Unreal animation or exact level character placement claimed. 14 Python tests with Matya fixtures and five Blender executions (character gallery, accessory binding, both cooked skeletal profiles, smoke) passed. User assets excluded.
