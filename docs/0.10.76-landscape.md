# 0.10.76-dev — saved landscape geometry in full-scene transfer

Select an original UE5.6 project, scan, select a level, and click **Import Complete Saved Level (Preview)**. The native landscape reader is also included in the editor geometry stage. The existing `UE_EDITOR_PAYLOAD_DECODER` must be configured; no new external assets are required. Strict dependency mode continues to refuse missing source packages.

Supported profile: inline `Landscape` actor, explicitly owned root and component list, one unique embedded non-sRGB BGRA8 UEDELTA height texture per component, contiguous local trailer payloads, full mip-chain byte extent, unoffset heightmap mapping, rectangular grid of one or two subsections per axis. Only the finest source mip is decoded. Payload identity/CRC/BLAKE3, source color extrema, exact serialized component height bounds, subsection borders and all adjacent component borders must agree. Sparse grids, streaming proxies, missing or virtualized payloads, layers, holes, XY offsets, unsupported transforms and mismatched seams are reported rather than guessed.

The importer removes duplicated subsection and component border samples and produces one editable welded quad mesh, using source `R*256+G-32768` height codes, divided by 128, with saved root transform and Unreal-to-Blender axis/unit conversion. It preserves the original material package reference and per-component source payload hashes as metadata. The mesh is not a reconstruction of runtime tessellation, material layers, collision, foliage or Nanite. Quads are an editable representation of the sampled surface, not a claim of identical Unreal triangle diagonals. Material remains explicitly unresolved.

Original ShooterSam MainLevel: 64 heightmaps of 128x128, 112 shared borders with zero code disagreement, 1009x1009 unique samples, 1,018,081 vertices, 1,016,064 quads, horizontal span 2520 m on each axis. All vertex coordinates independently compared with the source grid and saved root transform before/after Blender 4.2.4 reopen; max world coordinate component difference 0.000172 m. MainLevel still lacks 227 environment mesh packages and its terrain material. One-click level transfer includes six enemy armatures, six camera previews and 141 light previews; unresolved geometry anchors are not real meshes. The original data remains unchanged.
