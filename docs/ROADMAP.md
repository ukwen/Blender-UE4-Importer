# Full scene transfer roadmap

Goal: direct one-operation import of original Unreal project level into a faithful, editable Blender scene, no FBX/USD export or gameplay emulation. Support UE4 legacy and bounded UE5 profiles; no general compatibility claim.

- Established profiles: project discovery, native static/skeletal geometry, skinning, reference skeletons, authored animation decoding, root translation separation, external pose comparison; material expression subsets, packed textures, saved Blueprint components, saved character placement, light/camera previews. See DEVELOPMENT.md and version-specific notes for evidence and scope.
- 0.10.74 unified saved level import; 0.10.75 recursive dependency gate and five level tests; 0.10.76 saved heightfield reconstruction (64 components, 1,018,081 vertices; previous acceptance); 0.10.77 instance component inventory diagnostics and reproducible recovery. Inventory is not a native instance decoder.
- Next: inspect existing original UE5/legacy fixture inventory for native ISM/HISM/foliage payloads. Implement exact bounded reader only when source format evidence supports it, validate transforms, mesh/material sharing, world placement, duplicate refusal and save/reopen. If absent, use controlled tests for the builder and prioritize remaining original visual actor types without inventing a format.
- Further: landscape layer materials/holes/proxies, decals, streaming/level instances, remaining saved actor and Blueprint attachment types; improve scene materials and texture fidelity, animation bindings and camera/light fidelity. Broader UE5.7 editor geometry, animation and package compatibility. Improve UI, performance, memory use, diagnostics, integrated and independent commercial scene acceptance and Windows distribution.
- Blocked: source MainLevel assets missing; terrain material absent; Wraith skeleton and five material mappings unresolved; no UE runtime references for rendering/animation equivalence; broader independent commercial fixture acceptance not verified. Do not request further downloads until feasible existing-asset work substantially complete and user approves.
