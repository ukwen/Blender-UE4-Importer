# 0.10.19-dev: material attribute bundles

Implemented editable Make, Break and Blend Material Attributes for eight surface fields in the existing importer. Native FName-based 36-byte MaterialAttributesInput is decoded; unknown layouts remain unsupported. UE4 Break output indices 0–7 correspond to BaseColor, Metallic, Specular, Roughness, EmissiveColor, Opacity, OpacityMask, Normal. Bundles are separate named numeric sockets, not a shader closure. Blend interpolates fields with unclamped numeric Mix, with UseA and UseB selection implemented; normal values remain numeric until the root tangent-space conversion. Root attribute mode routes supported fields to Principled or existing remapped sockets, with opacity and mask distinct. Unsupported connected fields and ordinary links from a bundle mark Error. Material attribute function inputs and inherited blend-mode changes are explicitly incomplete. No claim of full Unreal layer/compiler fidelity.

Reference semantics: Epic UE4.27 Material Attributes Expressions (https://dev.epicgames.com/documentation/unreal-engine/material-attributes-expressions?application_version=4.27); Epic UE4.27 BlendMaterialAttributes Python API; UE4.23 MaterialShared.cpp FMaterialAttributesInput native serialization inspected in public UEToonStylized source. Implementation independently written.

Controlled tagged binary record and mocked package export graph exercised actual ImportNodeGraph, LinkSockets and existing global parameter override path. Seven Cycles CPU linear EXR field comparisons passed, max error 3.5762786843029915e-08, including two weights, separate opacity/mask and UseB. Save/reopen and invalid field/bundle rejection passed. 14 Python tests, 21 Blender 4.2.4 scripts passed, including prior genuine Goblin asset tests. New test: tests/blender_material_attributes.py. No genuine layered material package yet; Set/Get GUID mapping, bundle function transport, static material attribute switches, vertex attributes, advanced shading models and exact Unreal visual comparison remain open. No user assets committed. Master preserved.
