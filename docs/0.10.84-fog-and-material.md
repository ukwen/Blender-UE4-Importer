# 0.10.84-dev — material guards and finite fog preview

The base-property audit distinguishes active, inactive, shadowed and unresolved overrides. Only a true serialized flag plus a valid explicit opacity threshold can change the inherited mask threshold. The controlled test confirms child precedence. MI_GlowNT's active blend and shading flags lack serialized values, so no engine defaults are guessed; TwoSided is stored without an active flag. Other base properties, float4 alpha and arbitrary material vector widths remain unsupported. A bounded RGB per-channel Lerp helper supports scalar and vector factors without clamping; vector factors explicitly report partial preview. The controlled Blender emission test has maximum RGB error 1.91927e-06; the original scalar-factor M_SimpleGlow regression remains passing.

Four original UE5.6 maps save one explicit density-only ExponentialHeightFog record with zero rotation/unit scale. A plan is recorded with scene transfer, but no new geometry or world changes happen automatically. In the project panel choose the already imported level and **Toggle Selected Level Fog Preview**. This builds one finite volume scattering box around the reconstructed mesh bounds plus 5 m margin; repeating toggles the same object. Source Z in cm maps to Blender metres, original density 0.043600000441 is retained. The preview uses that numerical value as a coefficient in 1/m, a chosen 0.01/m height falloff, white scattering and cap 1/m. These are not calibrated Unreal settings. The node values are editable. Unsupported or absent density, extra fields, excessive extents, multiple actors and nontrivial transforms are refused. Preview volume is not counted as original geometry; original coverage report is unchanged. No UE start distance, second fog, atmospheric coupling, rendering parity or EEVEE guarantee.
