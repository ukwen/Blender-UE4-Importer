# 0.10.9-dev: Native UE4 editor source texture and material lookup

The new reader consumes the versioned monolithic UE4 Texture2D export's tagged Source property table, native strip flags, bulk-data header and uncooked marker. For the tested profile, decompresses zlib chunks and validates the source PNG framing, CRCs, dimensions and bounded decoded scanlines. Synthetic raw BGRA8 and G8 cases validate swizzle and mip lengths; RGBA8 implemented but genuine raw assets and other layout branches are unverified. Input profile permits UE4 package object versions 513–522; genuine accepted samples only 513 and 518. UE5 editor bulk, virtualized source, HDR, JPEG, split editor assets and broader source formats are not supported. No thumbnails used as textures.
