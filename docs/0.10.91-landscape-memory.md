# 0.10.91-dev — landscape memory and all-level acceptance

Regular terrain coordinates and quad indices now use separable 1D arrays and contiguous float32/int32 output buffers. Source atlas corner UVs and component IDs use broadcasting; temporary UV arrays are released before PNG generation. No changes to vertex order, triangulation policy, geometry scale, atlas bytes or material binding. Controlled rectangular/negative-origin fixtures compare the old formulas byte-for-byte. The original full MainLevel A/B harness runs with cache disabled in separate processes and hashes all terrain coordinates, loop indices, polygon extents, component IDs, atlas UVs, packed image and matrix, with reopen validation. Source and candidate digests are exact. Observed peak RSS 889815040 to 878694400 bytes (848.59 to 837.99 MiB), 12.4814 to 12.8348 seconds. Other tests were running during the candidate measurement, so no timing improvement or portable memory guarantee is claimed.

The original project has seven `.umap` files but six worlds. `MyStuff/TestLevel.umap` is a 1261-byte UE5.6 ObjectRedirector with target `/Game/MyStuff/Maps/TestLevel`. Discovery excludes only the validated bounded single-root redirector profile (<=1 MiB, UE5 1016/1017, exact serialized target World reference); records source and destination in project settings. Unknown/malformed packages remain visible. No auto-follow, arbitrary redirector resolution or legacy redirector claim.

Whole-project acceptance: actual registered checked-level import of six original worlds; 3856 objects (including diagnostic anchors/guides), 444 reconstructed scene meshes and 7 armatures. Independent level visibility and exact reopened per-level object/mesh/UV/material-index digests, camera/world preservation and duplicate refusal. This is independent map transfer, not native streaming composition or complete visual fidelity. The original projects remain incomplete. Both Western Frontier original maps and the partial Goblin fixture were revalidated using hash-verified existing inputs. 2814 Western meshes, 36 rigs, 462 linked foliage instances, 5 packed images; Goblin 36 meshes, 30 rigs, 3 packed images. See JSON and logs in Library release checkpoint. No new assets.
