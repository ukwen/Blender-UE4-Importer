# 0.10.93-dev — report navigation

The primary Unreal sidebar now opens the selected level's stored transfer report, its containing independent level-set report, selected source actions, and an explicitly labelled last-operation report. Each visible report has a copy button. A Text Editor is reused when available; otherwise the current editor changes to Text Editor. Return to 3D Viewport using the editor selector (Shift-F5).

Selected-level reports are resolved through the current scene's collections and exact saved source path, not the most recent batch report. Missing and ambiguous collection/report references are refused; selected level/set JSON identity is checked when opening or copying. No filesystem writes, geometry changes or native runtime claims. Last-operation report is intentionally historical and not selected-level scoped.
