# UE5 object-version 1004 editor source profile

Use the pinned original ShooterSam project at commit `1623ccdeac924ae0a1ec76289033e9ffa19d9f8a` and the separately built payload decoder described in the 0.10.61 notes. Only tagged monolithic editor files with UE4 version 522 and UE5 version 1004 are accepted by the legacy reader. Imports are 40 bytes and exports 108 bytes; old property tags are decoded separately from newer type trees. Texture source extraction validates the serialized inline offset, compressed header, payload hash and PNG framing. No magic scanning. `T_GridChecker_A` returns the original PNG byte stream, 512 x 512, non-color. Gray_02 and TopDark preserve six and seven global parameter overrides, respectively. Both resolve the exact modern parent. TopDark's two conflicting parameter GUIDs and the unresolved procedural material functions are reported; no guessed shader equivalence.

Run with `UE56_EDITOR_PROJECT` and `UE_EDITOR_PAYLOAD_DECODER` configured:

```
python -m unittest discover -s tests -p 'test_ue5_legacy_editor.py'
blender -b -t 4 --python-exit-code 1 --python tests/blender_ue56_legacy_editor.py
```

The Blender test also requires `UE56_EDITOR_OUTPUT` (output .blend path). It checks exact packed PNG bytes, cache reuse, legacy instance parameter metadata, partial shader status and independent reopen. Pillow is required by the host-independent PNG fixture test. Older summary soft-reference tables remain unknown; import-table inspection is not full dependency or shader coverage. This profile does not imply all UE5.0 assets or arbitrary old tagged property types are supported. Windows command-line decoder acceptance was completed separately for 0.10.61; no native Windows Blender test or distributable installer is claimed here.
