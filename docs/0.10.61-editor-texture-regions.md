# UE5 editor texture restart regions and external decoder portability

Original fixture: ShooterSam commit `1623ccdeac924ae0a1ec76289033e9ffa19d9f8a`. The original 32-row assumption was wrong for smaller textures. Observed power-of-two width restart interval is `min(height, max(32, 32768 // width))`. For the original 1254 x 1254 opaque mask, the serialized alpha extrema establish constant alpha 255; the encoded alpha bytes expose two contiguous regions [0,640), [640,1254) with independent periodic restart rows 53 and 55. The bounded non-power-of-two path refuses variable-alpha data and irregular markers rather than guessing. This is an observed source profile, not a universal implementation of every Unreal TextureSource codec.

Full fixture audit: 51/51 inspectable modern textures passed BLAKE3, size, header CRC, serialized RGBA extrema and independent Pillow PNG byte verification; 41 previously accepted images retain identical pixel hashes, one (`MagGun_Decals`) changes due to the corrected restart interval, nine previously rejected images now decode. One older texture package was not inspectable. No external original bitmap/Unreal-export reference is available; extrema and reversible synthetic fixtures are not independent ground truth for each pixel. Cache keys and material-enabled batch fingerprints are deliberately revised, so old imported materials cannot silently be reused. Existing scenes are not modified. Use a fresh batch/scene for corrected images.

Materials: supported scalar math, reroutes, masks and plain texture samples with no connected coordinate/mip overrides; exact sampler address mode when X/Y match, explicit nearest filtering. AO data is preserved as a labelled unconnected branch because Principled has no equivalent AO input. Unsupported function packages are identified by exact path. Do not claim shader equivalence: runtime first-person masks, engine material functions, procedural grid, tangent-space basis and VFX still partial. The actual mannequin surface/material acceptance and source flat-color inheritance regression passed.

## External helper on Windows x64

Separate pinned pyooz and BLAKE3 sources are documented in [0.10.55](0.10.55-ue56-editor.md). Use trusted original assets only; subprocess isolation is not a security sandbox. The helper validates CRC before native decompression, caps input/output, checks BLAKE3 and enforces binary stdin/stdout on Windows. Build using x64 MinGW-w64 GCC/G++ on PATH (e.g. UCRT64). Open CMD:

```bat
call tools\build_editor_decoder.cmd "C:\Sources\pyooz" "C:\Sources\blake3\c" "C:\Tools\ue_editor_decode.exe"
set "UE_EDITOR_PAYLOAD_DECODER=C:\Tools\ue_editor_decode.exe"
python tools\verify_editor_decoder.py "C:\Projects\ShooterSam\ShooterSam.uproject" "%UE_EDITOR_PAYLOAD_DECODER%"
start "" "C:\Program Files\Blender Foundation\Blender 4.2\blender.exe"
```

Linux: same verification script with `tools/build_editor_decoder.sh` and the compiled executable. The script verifies four pinned real compressed buffers (including binary byte sequences), exact decoded SHA-256 from the accepted Linux decoder, valid method-0 stream, and corrupt CRC/payload refusal. No decoder binary or third-party code is bundled. Windows runtime test is a separate acceptance gate; Linux build and runtime pass.
