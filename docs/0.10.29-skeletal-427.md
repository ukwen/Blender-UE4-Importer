# 0.10.29-dev: native UE4.27 skeletal render mesh profile

Explicit UE4.18 and UE4.27 profiles in the native skeletal mesh operator. UE4.27 reader consumes tagged SamplingInfo, version-specific material records, single inline render LOD, section palettes, overlap metadata, separate position, signed packed tangent/normal, UV and fixed 8-bit skin weight buffers, adjacency and checked block/trailer extents. Source import vertex map not available in this profile; no fabricated mapping. Materials remain named placeholders. Variable influence layouts, wide bone indices, cloth, external render buffers, high precision tangent basis, morph targets, additional LODs and other versions are unsupported or unverified.

Positions, face order, weights, UVs, bone transforms, material references and per-face assignments exactly equal 4.18 decoded values. Neutral recovery and authored test action save/reopen pass. Both native skeletal profiles passed separately, plus five targeted Blender scripts and 14 Python unit tests.
