# UE5.6 native editor source textures and material graph subset

Fixture: ShooterSam original source at `1623ccdeac924ae0a1ec76289033e9ffa19d9f8a`. Requires the separately built experimental `UE_EDITOR_PAYLOAD_DECODER` from 0.10.55. No source pixels are substituted. UEDELTA BGRA8 single-mip, single-slice, single-layer local source data: vertical unsigned byte differences with absolute scanlines every 32 rows. Validate trailer identity, size, CRC, BLAKE3 and serialized source extrema, including legacy gamma 2.2 where explicitly serialized. 42/51 inspectable Texture2D packages passed; nine rejected for alpha and/or RGB extrema disagreement (one older texture package is not inspectable). PNG RGBA checked independently using Pillow. No external source bitmap or Unreal engine pixel export was available; extrema do not prove every decoded pixel independently. Preserve raw alpha and fail closed on mismatch. No unsupported texture format, multi-mip, virtualized bulk data or arbitrary gamma profile claimed.

Material translator reads complete-type-name tags, expression references and channel masks, material output links, global scalar/vector/texture/static-switch overrides and exact local parent chains. 27/35 filename-selected M_/MI_ packages resolved; eight remain unavailable or unsupported. Three flat-color materials (parent, child and grandchild) connected their serialized PBR parameters. Four Manny/Quinn instances connect original base color, metallic, roughness and normal inputs; 12 packed textures with source pixel SHA-256. Normal basis, masked opacity, AO, runtime/particle expressions and engine material functions remain partial, not equivalent shaders. The translator does not execute arbitrary HLSL. Strict mode disconnects unresolved graphs from the surface; partial mode is an explicit opt-in. Original graph metadata and diagnostics are attached to the Blender material. Existing imported materials are not mutated. Source texture addresses/flip flags are retained as metadata, not all translated to sampler nodes.

Use Project Browser > Geometry Folder or Selected Map > UE5 editor materials / Bind materials, and opt in to Keep incomplete surface previews for the mannequin. Legacy geometry-only sessions continue to reuse as before; material-enabled modern editor jobs use a new settings fingerprint. Changing the partial setting blocks stale reuse. Save/reopen tested both original skinned characters and one original map. Geometry-only map and skeletal source regression tests remain available. Full UE4 map reconstruction not rerun. Original animation is still unimplemented (modern editor uses FK Control Rig MovieScene data model rather than legacy raw track arrays).

Acceptance commands: set `UE56_EDITOR_PROJECT`, `UE_EDITOR_PAYLOAD_DECODER`, `MATYA_ASSETS`, `UASSETAPI_ASSETS` and `UE56_EDITOR_OUTPUT`; run `python -m unittest discover -s tests -p 'test_*.py'`, `blender -b --python-exit-code 1 --python tests/blender_ue56_editor_material.py`; set `UE56_TEXTURE_REPORT` and run `python tests/audit_ue56_editor_textures.py` for all inspectable original textures. 45 unit tests passed, no skips with reference fixtures. Local Blender 4.2.4 integration passed, including blocked_stale check.
