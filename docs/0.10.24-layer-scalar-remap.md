# 0.10.24-dev: inherited scalar replay across detached layer snapshots

Successful scoped scalar overrides are retained during the import chain and remapped when a later complete detached snapshot reorders the same function packages. Layer identity uses stable layer GUID; blend identity uses the upper layer GUID and unchanged blend package. The staged replacement must retain matching typed target counts. Replaying inherited values happens before committing the swap. Explicit current-instance overrides still apply after replacement. Missing or disabled overridden layers, changed function packages, ambiguous identity, unsupported prior scoped kinds, and unresolved prior records block replay. Parent-linked topology reconciliation, inherited scoped vectors/textures/switches, and default stacks without accepted snapshot identities remain outside this bounded profile. This is a conservative import strategy, not proven general Unreal inheritance equivalence.
