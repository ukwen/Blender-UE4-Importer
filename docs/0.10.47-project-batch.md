# 0.10.47-dev — Project batch workflow

The Unreal sidebar now offers **Project batch workflow**. Choose All maps, Selected map (scan and select first), or Geometry folder (relative to Content). Set material/component options for maps or native physics previews for geometry. Choose Dependency Preflight to produce a JSON Text Editor report without creating scene objects. Run Batch Import rebuilds the plan, processes jobs one at a time, and publishes a batch report. Esc stops between jobs, retaining completed work; the current native decoder cannot be interrupted. Background operator execution is synchronous. Select the report text in Blender's Text Editor. Save your .blend to retain the reports. Rerunning imports creates new galleries/collections; automatic resume/deduplication is not implemented.

Preflight uses exact package identities and follows conservative import-table references within Content, including supported UE5 1012 tables. External engine references and unsupported mounts are distinguished from missing Game references; engine dependencies are not recursively inspected. Cooked split/unsupported/invalid tables have unknown coverage. Soft references, dynamic Blueprint execution, and runtime dependency usage are not inferred. All maps exclude external-actor/object directories. Geometry plans only known geometry or packages of unknown class. Batch map jobs invoke native reconstruction (not the legacy map command); geometry uses existing gallery routing. Per-job errors continue to next job. Map errors remove newly created IDs in tracked stores, not a transactional rollback of edits to existing IDs or disk files. Job completion means attempted, not all assets resolved. Modal UI event handling was not interactively exercised; cancellation boundary was tested by closing the real generator.
