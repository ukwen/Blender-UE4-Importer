# 0.10.66-dev — targeted missing mesh recovery

Restore original mesh package files at their exact project or configured engine Content-relative paths first. In Blender's Viewport Sidebar → Unreal, scan the same project, select the original level, select the missing mesh empties from its imported collection, optionally enable editor materials/partial previews, and choose **Repair Selected Missing Meshes**.

- Native UE5.6 editor 1016/1017 monolithic StaticMesh recovery only. The saved actor/component identity, source level, referenced package and material override list must match the current serialized records. Newly imported collections carry the exact source map path. Older collections with matching report/actor data may be repaired using the explicitly selected project; original absolute project provenance was not recorded in those versions.
- Require exact serialized package identity in the package summary plus the root StaticMesh name, and verify its SHA-256 before/after decoding. This checks identity and stable bytes, not provenance from an independent trusted original. No near-name matching or substitute geometry. Wrong identity, unsupported format and absent source reported. A bounded source reader verifies payload hashes as before. Read each recovered mesh once per run; share mesh data across instances.
- The new overlay collection contains mesh children at identity local transforms under the original missing anchors. This preserves edits, parenting and animation of anchors, and leaves original collection membership and original report untouched. Each recovery child contains the source SHA-256, settings fingerprint and original reference metadata. Existing children are not replaced; different source bytes/settings block reuse. Repeated calls produce separate diagnostic report texts but not duplicate geometry. To remove a repair, delete the overlay children explicitly; remove overlay before a complete map reimport. Batch source fingerprint protection still applies to the original collection. Material binding is optional and partial graphs remain labeled; material dependency changes and user-edited geometry are not certified by an existing-repair result.

Three material packages inspected (one supported PBR subset, two partial). Duplicate prevention and stale-source block passed before and after reopen. Original source project unmodified. The inspection .blend refers to the disposable test project path; use it for inspecting results, not retrying against that deleted path.
